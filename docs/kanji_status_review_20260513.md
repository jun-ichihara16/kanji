## 8. Manus に依頼すべきこと（叩き候補）

ユーザーの希望: 「直近のベスプラを踏まえて何をすべきか」整理してもらう。

### 候補A: ロードマップ整理に絞る
- インタビュー結果と Phase 2 戦略の差分を洗い出す
- Phase 2 Week 4 の実装順序と依存関係を整理
- 「次の 2 週間で何を出荷すれば PMF Gate に近づくか」を提示

### 候補B: 戦略修正提案まで踏み込む
- 候補A に加え、インタビュー結果から得た新インサイトで Phase 2 戦略の修正案を提示
- 北極星指標の見直し可否
- 優先施策 Top 5 の組み替え案

### 候補C: 実装着手まで一気通貫
- 候補B + Manus が migration 008 や Admin Dashboard の実装まで担当
- ただし Manus に実装させると後でレビュー必須

### 推奨

**候補B**。理由：
- インタビュー結果が戦略文書に未反映なので、戦略のすり合わせから始めるのが順序として正しい
- 実装は私（Claude Code）と並走させた方がレビューしやすい
- Manus の強み（リサーチ + 構造化）を最大化する依頼
